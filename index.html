Project Clipper

A personal desktop application for publishing short-form video clips.

What it does

Project Clipper is a command-line desktop application that runs locally on its owner's computer. It takes a long video file, transcribes the speech, selects self-contained segments, crops them to a 9:16 vertical frame, burns in subtitles, and writes the resulting clips to a local folder.

It is built and used by one person for their own video channel. It is not a product, not a service, and is not offered to anyone else. There are no user accounts, no sign-up, and no hosted component of any kind.

How it uses the YouTube Data API

The application uploads finished clips to a single YouTube channel — the one owned by the operator of the application. It authenticates through Google OAuth 2.0 as that channel's owner.

API methodWhy it is used
videos.insert Upload a finished clip to the owner's own channel.
videos.list Confirm the processing and privacy status of a clip after upload.

The application does not read, collect, or display data belonging to any other channel or viewer. It does not request access to anyone else's account, and no other person can connect an account to it.

Scope of access

  • https://www.googleapis.com/auth/youtube.upload — to upload clips.
  • https://www.googleapis.com/auth/youtube.readonly — to check upload status.

Who operates it

A single independent developer. Number of users: one — the owner.
