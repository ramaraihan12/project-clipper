Privacy Policy

Project Clipper — effective 21 September 2026

Project Clipper is a personal desktop application operated by a single independent developer for their own use. This policy describes what the application does with information. It is short because the application collects very little.

1. No data is collected from other people

The application has no user accounts, no sign-up, and no hosted service. No one other than the owner can use it or connect an account to it. It therefore does not collect, receive, process, or store personal information belonging to any other person.

2. Information the application handles

The application handles only the following, and only on the owner's own computer:

  • Video and audio files supplied by the owner, together with transcripts generated from them. These are processed locally and never transmitted anywhere except as part of an upload the owner initiates.
  • Google OAuth 2.0 credentials and tokens for the owner's own YouTube channel, used to authorise uploads to that channel.

3. Google user data

The application requests the following scopes, used solely to publish the owner's own clips to the owner's own channel:

  • https://www.googleapis.com/auth/youtube.upload
  • https://www.googleapis.com/auth/youtube.readonly

Access and refresh tokens are stored locally on the owner's computer, in a directory excluded from version control, and are never transmitted to any server operated by the developer or by any third party. No server operated by the developer exists.

Google user data is never sold, never transferred to anyone, never used for advertising, and never used to train any model. It is used only to perform the upload the owner explicitly initiates.

4. Retention and deletion

Tokens remain on the owner's computer until they expire or are deleted. The owner can delete them at any time by removing the local credentials file, and can revoke the application's access at any time at myaccount.google.com/permissions. Source videos and intermediate files are deleted automatically after each run.

5. Sharing

Nothing is shared. There are no analytics, no tracking, no advertising networks, no third-party processors, and no data transfers of any kind.

6. Limited Use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Children

The application is not directed at children and is not used by anyone other than its owner, who is over 18.

8. Changes

If this policy changes, the revised version will be published on this page with a new effective date.
